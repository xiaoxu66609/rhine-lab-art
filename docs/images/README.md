## 更新方式

1. 按仓库 README 安装依赖与浏览器，运行 npm test 获取新的网页运行截图。
2. 实际打开截图，核对场景、文字、加载状态和图形错误后，按上表选择对应画面。
3. 仅复制确认的展示图至本目录；同步 README 图注与本文件的采集条件。
4. 原始检查记录继续保留于被 Git 忽略的 .artifacts/，不提交整套报告与截图。

静态截图不能证明完整动效或真实手机验收。
